# 📚 Telegram Book Publisher Bot

Telegram-бот для автоматической обработки и публикации электронных книг в Telegram-группы.

Бот принимает книги и дополнительные файлы, извлекает метаданные из EPUB, автоматически находит обложку, формирует публикацию и отправляет её в настроенные Telegram-группы. Данные пользователей и их настройки хранятся в **Google Sheets**.

## ✨ Возможности

* 📖 Загрузка электронных книг через Telegram.
* 📚 Поддержка форматов: `.epub`, `.pdf`, `.txt`, `.docx`, `.doc`, `.fb2`, `.mobi`
* 🖼️ Автоматическое извлечение обложки из EPUB.
* 📝 Автоматическое извлечение метаданных:
  * название;
  * альтернативные названия;
  * автор;
  * описание;
  * теги;
  * ссылки;
  * количество глав.
* 📑 Автоматический подсчёт глав EPUB через `toc.ncx`.
* 🧵 Создание отдельной темы форума для каждой книги.
* 📤 Публикация книги сразу в несколько Telegram-групп.
* 📎 Возможность прикреплять дополнительные файлы вместе с книгой.
* 👤 Система регистрации пользователей.
* 🔐 Управление доступом пользователей.
* 🚫 Бан и разблокировка пользователей администраторами.
* 👨‍💻 Разделение пользователей на:
  * переводчиков;
  * обычных издателей.
* ⚙️ Индивидуальные настройки переводчиков.
* 📚 Настройки глоссария.
* 🌐 Настройки переводчика.
* 🧹 Настройки фильтра.
* 📌 Выбор статуса книги.
* 📁 Настройка списка групп для каждого пользователя.
* 💾 Хранение пользователей и настроек в Google Sheets.
* ⏱️ Автоматическая очистка временных файлов после завершения или отмены публикации.

## 🏗️ Архитектура

Проект написан на Python и использует асинхронную архитектуру.

Основные компоненты:

```text
Telegram
    │
    ▼
┌─────────────────────┐
│      app.py         │
│                     │
│ Telegram Bot        │
│ FSM / Handlers      │
│ EPUB Parser         │
│ Publication Logic   │
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│    google_db.py     │
│                     │
│ Google Sheets DB    │
│ User Management     │
│ Permissions         │
│ Profiles            │
└─────────┬───────────┘
          │
          ▼
     Google Sheets
```

Основная логика бота находится в `app.py`. Для работы с Google Sheets используется отдельный класс `GoogleSheetsDB` в `google_db.py`.

### `app.py`

Основной файл приложения.

Содержит:

* Telegram Bot;
* обработчики команд;
* FSM-состояния;
* регистрацию пользователей;
* загрузку файлов;
* обработку EPUB;
* извлечение метаданных;
* извлечение обложек;
* создание Telegram-публикаций;
* управление группами;
* административные команды.

Бот использует `MemoryStorage` для FSM и `aiogram` для обработки Telegram-событий.

### `google_db.py`

Модуль работы с Google Sheets.

Google Sheets используется как простая внешняя база данных для хранения:

* Telegram ID пользователя;
* username;
* списка групп;
* статуса активности;
* прав администратора;
* JSON-профиля пользователя.

Данные пользователей дополнительно кэшируются в памяти на 5 минут, что уменьшает количество обращений к Google Sheets.

### `epub_guide.md`

Инструкция для авторов и переводчиков по подготовке EPUB-файлов.

Особенно важны корректно заполненные EPUB-метаданные, поскольку именно их бот использует для формирования публикации.

## ⚙️ Требования

* Python 3.x
* Telegram Bot Token
* Google Cloud Service Account
* Google Spreadsheet
* Telegram-группы, в которых бот имеет необходимые права администратора

Зависимости проекта закреплены в `requirements.txt`. В частности, используются `aiogram`, `aiohttp`, `BeautifulSoup`, `lxml`, `EbookLib`, `python-dotenv`, `gspread`, `gspread-asyncio` и `google-auth`.

Клонируйте репозиторий:

```bash
git clone https://github.com/yelyzavetazv-wq/tgbot.git
cd tgbot
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

```bash

```

### Linux / macOS

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 🔐 Переменные окружения

Создайте файл `.env` в корне проекта.

Минимально боту необходимы следующие параметры:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
SPREADSHEET_ID=YOUR_GOOGLE_SPREADSHEET_ID
GOOGLE_CREDENTIALS_JSON={"type":"service_account", "...":"..."}
```

### `BOT_TOKEN`

Токен Telegram-бота, полученный через **@BotFather**.

### `SPREADSHEET_ID`

ID Google таблицы, которая используется ботом в качестве базы данных.

### `GOOGLE_CREDENTIALS_JSON`

JSON-данные Google Service Account.

Бот читает JSON из переменной окружения и создаёт авторизованное подключение к Google Sheets. Для Service Account используются разрешения Google Sheets и Google Drive.

> ⚠️ Никогда не публикуйте настоящий `BOT_TOKEN` или `GOOGLE_CREDENTIALS_JSON` в GitHub.

Добавьте `.env` в `.gitignore`, если он ещё туда не добавлен:

```gitignore
.env
*.env
```

## 📊 Настройка Google Sheets

Создайте Google Spreadsheet и предоставьте доступ Service Account к таблице.

Первая страница таблицы используется ботом как основной лист.

Структура данных:

| Колонка | Назначение      |
| ------- | --------------- |
| A       | Telegram ID     |
| B       | Username        |
| C       | Telegram-группы |
| D       | Активен         |
| E       | Администратор   |
| F       | JSON-профиль    |

Бот автоматически читает пользователей из таблицы и обновляет необходимые поля при регистрации или изменении настроек.

## 🤖 Настройка Telegram-бота

1. Создайте бота через `@BotFather`.
2. Получите Bot Token.
3. Добавьте бота в необходимые Telegram-группы.
4. Выдайте боту права администратора.
5. Убедитесь, что бот может:

   * создавать темы форума;
   * отправлять фотографии;
   * отправлять документы;
   * отправлять сообщения.

Для публикации в форумных группах бот создаёт отдельную тему с названием книги.

## 🚀 Запуск

После настройки переменных окружения:

```bash
python app.py
```

Основной код приложения создаёт Telegram Bot и Dispatcher, а в режиме запуска настраивает aiohttp-приложение с webhook endpoint `/webhook`.

> Для production-развёртывания необходимо дополнительно настроить внешний HTTPS endpoint и инфраструктуру, которая будет направлять Telegram webhook-запросы на `/webhook`.

## 📖 Работа с ботом

### Первый запуск

Пользователь отправляет:

```text
/start
```

Если пользователя ещё нет в базе, бот предлагает:

1. выбрать группы публикации;
2. выбрать роль;
3. при необходимости настроить инструменты переводчика.

По умолчанию может использоваться группа `РиФ`.

### Роль издателя

Обычный пользователь может просто отправлять EPUB-файлы для публикации без дополнительных настроек переводчика.

### Роль переводчика

Переводчик может настроить:

```text
📚 Глоссарий
🌐 Перевод
🧹 Фильтр
📌 Статус
```

Можно использовать стандартные варианты или добавлять собственные настройки.

## ⚙️ Команды

### `/start`

Регистрация и авторизация пользователя.

### `/help`

Показывает инструкцию по работе с ботом.

### `/settings`

Открывает настройки профиля переводчика.

### `/groups`

Позволяет изменить список групп, в которые будут публиковаться книги.

Пример:

```text
@groupexample, -1001234567890
```

### `/ban`

Команда администратора для блокировки пользователя:

```text
/ban @username
```

или:

```text
/ban 123456789
```

### `/unban`

Разблокировка пользователя:

```text
/unban @username
```

или:

```text
/unban 123456789
```

## 📚 Загрузка книги

Пользователь отправляет боту файл.

Бот:

1. проверяет доступ пользователя;
2. проверяет размер файла;
3. проверяет расширение;
4. сохраняет файл во временную директорию;
5. собирает несколько файлов в одну пакетную загрузку;
6. ищет основной EPUB;
7. извлекает метаданные;
8. извлекает обложку;
9. определяет количество глав;
10. показывает меню настроек;
11. после подтверждения публикует книгу.

Размер одного загружаемого файла ограничен **20 МБ**. EPUB является основным файлом публикации, а остальные поддерживаемые файлы могут использоваться как дополнительные вложения.

## 🖼️ Обложка EPUB

Бот пытается найти обложку внутри EPUB.

Сначала проверяется `titlepage.xhtml`, после чего выполняется поиск изображений `.jpg`, `.jpeg` и `.png`.

Найденная обложка используется как изображение первой части публикации.

## 📝 Формирование публикации

Публикация автоматически формируется из метаданных EPUB.

В неё могут попасть:

```text
🏴‍☠️ Название
🇬🇧 Альтернативное название
🌐 Название оригинала

✍️ Автор
📊 Количество глав
📌 Статус

🏷 Теги

📖 Описание

🔗 Ссылка

👤 Опубликовал
```

Для переводчиков дополнительно формируется подпись:

```text
🤖 Глоссарий
🤖 Перевод
🧹 Фильтр
```

## 🧵 Публикация в Telegram

Для каждой настроенной группы бот:

1. создаёт новую тему форума;
2. использует первое название книги как название темы;
3. отправляет обложку;
4. отправляет описание и метаданные;
5. отправляет EPUB;
6. отправляет дополнительные файлы.

Публикация может выполняться сразу в нескольких группах.

## ⏱️ Временные файлы

Загруженные файлы сохраняются во временной директории.

Если пользователь не завершает процесс публикации в течение 3 минут, бот автоматически:

* отменяет текущую операцию;
* удаляет временные файлы;
* очищает состояние FSM.

При успешной публикации или ручной отмене временные файлы также удаляются.

## 📖 Требования к EPUB

Для корректной работы рекомендуется внимательно заполнять EPUB metadata.

Особенно важны:

* `Title`
* `Creator`
* `Subject`
* `Description`
* `Publisher`
* содержание книги / `toc.ncx`

Если у книги несколько названий, они могут быть указаны через `/`:

```text
Русское название / English Title / Original Title
```

Первое название используется ботом как основное название публикации и темы Telegram-форума.

Подробная инструкция находится в [`epub_guide.md`](./epub_guide.md).
